{% load i18n %} {% comment %} Stacked, full-width report layout (the default). Five full-width (``col-12``) sections, in order: Run Summary, User Inputs, Outputs, Signed Credential, and Evidence Manifest. The last two render only when the run has their corresponding proof artifact. - Run Summary is a plain card (header + two-column body + footer). Its metadata is laid out in two equal columns that stack on mobile (``split=True``), and the "View report as JSON" action lives in the card footer. - The four detail sections are independent Bootstrap accordions (no shared ``data-bs-parent``). They default closed, then the front-end restores each section's most recent open/closed state from session storage. User Inputs and Outputs use ``bare=True`` so the accordion supplies their chrome. Generated Files remains an independent nested accordion inside Outputs. Selected by ``validation_detail.html`` by default. The original two-column design lives in ``layout_validation_run_classic.html`` for a future toggle. Context variables: run, step_runs, step_outputs, step_params, step_template_warnings, artifact_items, issued_credential, credential_download_url, evidence_artifact (all forwarded from the run detail view). {% endcomment %}
